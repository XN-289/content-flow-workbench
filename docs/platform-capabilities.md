# 平台能力矩阵

- 版本：v0.4
- 日期：2026-10-22
- 实现位置：`scripts/platform-capabilities.mjs`、信息流页“平台能力矩阵”

## 1. 状态口径

能力只使用四种状态：

| 状态 | 含义 |
|---|---|
| `complete` | 当前实现能在安全边界内稳定拿到对应层级 |
| `partial` | 只能拿到部分内容，或依赖人工可见范围、人工复制和公开源可用性 |
| `unsupported` | 当前明确不做自动化，只保留人工或平台导出通道 |
| `unknown` | 能力尚待确认；不得为了界面好看伪装成完整支持 |

## 3. 详情证据口径

小红书详情采集书签只在用户人工打开对应笔记详情页后运行。它读取当前页面可见状态和已加载的媒体信息，写入标题、正文、封面、媒体清单、原始页面文本和逐字稿状态。平台未暴露逐字稿时写入 `missing`；登录墙或风控限制导致不可读时写入 `blocked`；两者都不伪造。发现字幕文件链接但未下载解析时，也保持 `missing`，只在说明中记录链接存在。

2026-10-21 已用真实 Chrome Guest 和用户提供的 4 条可读详情页验证成功路径。正文、封面、媒体清单、raw snapshot 和证据包全部落库；平台页面未暴露逐字稿文本，后续由用户在 4 条信号上逐条显式触发本地 ASR，均取得候选全文。媒体计数是清单项，包含平台返回的主图、预览、视频和多 CDN / 备用地址，且默认不下载。

| 匿名样本 | 正文 | 媒体清单项 | 逐字稿 |
|---|---:|---:|---|
| 样本 A | 355 字 | 17 | captured（1,995 字 / 55 段） |
| 样本 B | 264 字 | 14 | captured（1,456 字 / 155 段） |
| 样本 C | 128 字 | 11 | captured（1,665 字 / 100 段） |
| 样本 D | 99 字 | 11 | captured（894 字 / 77 段） |

4 个证据包在本地 ASR 后均重建为 `candidate-transcript` 层，`checksums.sha256` 各含 6 条记录，逐条重算后全部匹配；证据核对状态均为 `unverified`。本轮 4 次详情访问均未遇到滑块、人机验证或安全验证页。

### 本地 ASR 逐字稿

小红书不会在当前游客详情页暴露这批笔记的逐字稿文本，因此工作台不把正文、话题标签或字幕文件链接当作逐字稿。Inbox 对已有完整 MP4 媒体清单的单条信号提供显式“生成逐字稿”动作：下载该信号的一个完整 MP4，用 ffmpeg 转成 16 kHz mono WAV，再调用本机 faster-whisper small int8 CPU 模型转写。整个过程不使用 `.m4s` 分片，不批量下载媒体，不调用平台私有接口。

2026-10-21 已用用户提供的 4 条详情完成真实验收：样本 A 1,995 字 / 55 段 / 260.851 秒，样本 B 1,456 字 / 155 段 / 203.475 秒，样本 C 1,665 字 / 100 段 / 234.984 秒，样本 D 894 字 / 77 段 / 165.674 秒，来源均为 `local-asr:faster-whisper-small-int8-cpu`。产物保存在本地 ignored 目录 `data/transcripts/`，并进入证据包的 `candidate/transcript.md` 待人工校对层；ASR 同音字、标点和术语错误不得直接当作已核实事实引用。

### B 站公开字幕

B 站公开视频优先通过 `yt-dlp` 读取标题、简介、作者、封面与公开字幕轨，不下载视频。JSON3 / SRT / VTT 字幕会统一成带 `start`、`end`、`startTimestamp`、`endTimestamp` 的分段；字幕状态为 `captured`，证据状态仍为 `unverified`。没有公开字幕时写入 `missing`，简介不会被当成逐字稿。HTTP 412 / 403、登录墙或风控写入 `blocked`，等待人工在浏览器确认。

## 4. 登录与风险边界

- X：只用无登录公开可见范围；不保存登录态，不调用私有接口；登录墙和风控页记录 blocked / failed。
- 小红书：只读取用户手动滚动后页面已加载状态；不自动滚动，不做后台全量抓取。
- 抖音：不做登录态后台采集；只接受公开链接、人工复制或平台导出；不做签名、验证码、代理或指纹伪装。
- B 站：只读取公开视频、主页或合集；不使用登录态；412 / 403、登录墙和风控一律记录 blocked。
- 公众号：只访问公开文章页；RSS / 公开页面失败时保留失败运行，不生成假信号。

新增平台 adapter 时必须先声明上述状态、采集方法、登录边界和风险边界；`unknown` 只有经过真实验证并保留证据后才能升级。
